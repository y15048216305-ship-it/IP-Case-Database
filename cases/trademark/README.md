本目录用于收录和整理知识产权中的商标案件，特别是商标侵权、商标混淆、驰名商标保护等类型案件。

## 目录说明

每个案例目录中通常包括：
- `case-info.md`：基本案情与案件信息
- `full-judgment.md`：判决书摘要或公开材料整理
- `legal-analysis.md`：法律分析
- `reference.md`：参考资料和链接

## 适用研究方向

- 商标注册与使用
- 商标侵权与混淆
- 驰名商标保护
- 平行进口与品牌维权
- 商业标识与消费者认知
