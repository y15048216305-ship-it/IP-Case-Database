# 分类标准 | Case Categories

本项目按照知识产权内容进行分类，便于学生和研究者快速定位不同类型案例。

## 一、总体分类

### 1. 商标案例 | trademark

主要包括：
- 商标注册争议
- 商标侵权
- 商标混淆
- 驰名商标保护
- 商标淡化
- 商标无效宣告

### 2. 专利案例 | patent

包括：
- 发明专利侵权
- 实用新型侵权
- 外观设计侵权
- 专利效力争议
- 技术方案与专利授权

### 3. 著作权案例 | copyright

包括：
- 作品侵权
- 改编与二次创作
- 著作权归属
- 信息网络传播权
- 作品使用许可争议

### 4. 其他知识产权案件 | other

包括：
- 不正当竞争
- 商业秘密
- 地理标志
- 反不正当竞争
- 域名与企业标识保护

## 二、案件管理原则

- 一案一目录：每个案例独立保留目录
- 统一模板：统一使用 `case-info.md` 与 `legal-analysis.md` 等文件名称
- 便于检索：添加统一标签与关键词
- 资料保真：所有资料要求注明来源

## 三、标签示例

- 商标侵权
- 知名品牌保护
- 商标近似
- 消费者混淆
- 作品归属
- 专利授权
- 竞争行为

## 四、建议研究路径

### 学生路径
- 先从商标案例入手
- 学习各类权利的构成要件
- 对比不同法院判决逻辑

### 研究者路径
- 关注案件趋势与法理变化
- 比对国内外同类规则
- 关注新领域知识产权问题
