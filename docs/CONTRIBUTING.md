# 贡献指南 | Contributing Guide

感谢您对本项目的关注！欢迎提交案例、完善文档或改进项目。

## 🚀 快速开始

### 1. Fork 本仓库
在 GitHub 上 fork 本项目到你的账户。

### 2. Clone 到本地
```bash
git clone https://github.com/YOUR-USERNAME/IP-Case-Database.git
cd IP-Case-Database
```

### 3. 创建新分支
```bash
git checkout -b feature/add-case-xxx
```

### 4. 添加或修改内容
按照下面的规范进行操作。

### 5. 提交 Pull Request
将你的改动推送回远程，然后向主仓库提交 PR。

## 📝 添加新案例

### 步骤一：确定案例分类

根据案件类型选择对应文件夹：
- `cases/trademark/` - 商标案件
- `cases/patent/` - 专利案件
- `cases/copyright/` - 著作权案件
- `cases/other/` - 其他知识产权案件

### 步骤二：创建案例目录

```
cases/trademark/[案例英文缩写]/
├── case-info.md
├── full-judgment.md
├── legal-analysis.md
└── reference.md
```

### 步骤三：按模板填写内容

参考 [案例模板](./CASE-TEMPLATE.md) 填写各文件。

## 📋 案例模板详解

### case-info.md（案例基本信息）

```markdown
# 案例名称

## 基本信息

| 项目 | 内容 |
|------|------|
| 案号 | XXXX年XXXX号 |
| 当事人 | 原告：xxx；被告：yyy |
| 审理法院 | xxx人民法院 |
| 判决日期 | XXXX年XX月XX日 |
| 案件类型 | 商标侵权纠纷 |

## 诉讼请求

1. 被告立即停止侵权行为
2. 赔偿经济损失 xxx 万元
3. 赔偿合理费用 xxx 万元

## 基本事实

简述案件的基本事实...

## 判决结果

法院支持/部分支持/驳回...

## 法律意义

这个案件的法律意义...
```

### legal-analysis.md（法律分析）

```markdown
# 法律分析

## 争议焦点

### 焦点一：xxxx

论述...

### 焦点二：xxxx

论述...

## 法院判决理由

逐点分析法院的判决逻辑...

## 法律原理应用

涉及的法律原理...

## 启示与借鉴

从本案可以获得的启示...

## 相关法律条文

- 《商标法》第xx条
- 《民事诉讼法》第xx条
- 其他相关法律...
```

## 🏷️ 标签系统

为案例添加合理的标签便于检索：

### 商标案件标签
- 商标侵权
- 驰名商标
- 商标混淆
- 商标淡化
- 商标异议
- 商标无效
- 地理标志

### 专利案件标签
- 专利侵权
- 专利无效
- 实用新型
- 外观设计
- 发明专利
- 技术方案

### 著作权标签
- 著作权侵权
- 作品权属
- 信息网络传播权

- 同人创作

  "year": 2026,

## ✅ 检查清单

提交 PR 前，请确保：

- [ ] 案例信息准确完整
- [ ] 遵循模板格式
- [ ] 文件名使用英文（中文名作为标题）
- [ ] 添加了相关标签
- [ ] 更新了 cases.json
- [ ] 检查了拼写和格式错误
- [ ] 提供了信息来源和参考资料

## 💡 贡献类型

### 完善现有案例

- 添加深度分析

### 改进文档
- 优化案例模板
- 改进分类系统

### 报告问题
- 发现错误信息
- 提出功能建议
- 分享改进意见

## 🎯 提交 Pull Request

### PR 标题规范

- 添加案例：`Add: [案例简称] - [基本信息]`
- 更新内容：`Update: [案例名] - [改进内容]`
- 修复错误：`Fix: [错误描述]`

### PR 描述模板

```markdown
## 描述
本 PR 的改动内容简述...

## 改动类型
- [ ] 添加新案例
- [ ] 更新现有案例
- [ ] 修复错误
- [ ] 改进文档

## 关联的案例
- 案例名：xxx
- 相关标签：xxx

## 检查清单
- [ ] 遵循项目规范
- [ ] 信息来源可靠
- [ ] 格式正确
- [ ] 无拼写错误
```
